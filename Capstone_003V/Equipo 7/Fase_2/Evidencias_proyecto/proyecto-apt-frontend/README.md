# Sistema APT - Frontend

Frontend desarrollado en React para el Sistema APT (Análisis y Planificación de Alimentos).

## 🚀 Instalación

```bash
npm install
```

## 🏃 Ejecución

```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`

## 🔧 Configuración

Asegúrate de que el backend esté corriendo en `http://localhost:4000`

## 📦 Módulos

- **Dashboard** - Vista general del sistema
- **Inventario** - Gestión de inventario FIFO
- **Productos** - Catálogo de productos
- **Proveedores** - Gestión de proveedores
- **Checklists** - Control de calidad
- **Producción** - Registro de producción
- **Reportes** - Generación de reportes PDF
